# AI Development Documentation

## 1. Project Overview

This project is a React-based Personal Expense Tracker developed as part of the Week 3 internship assignment.

The application allows users to:
- Add expenses
- Select an expense category
- Set an expense date
- View recorded expenses
- Delete expenses
- Filter expenses
- View total spending
- View spending by category
- Use a responsive user interface

Live Application:
https://internship-week-3-react-app.vercel.app/ 


## 2. AI Tools Used

AI was used as a development assistant throughout the project.

Tools used:
- ChatGPT
- Codex

AI was mainly used for:
- Understanding React concepts
- Planning component structure
- Generating and improving code
- Reviewing existing code
- Debugging errors
- Improving UI and CSS
- Suggesting refactoring and improvements
- Explaining errors and development issues

I did not rely on AI to blindly generate the entire project. I reviewed the suggested implementation, tested the application, and made changes based on the actual behavior of the application.


## 3. Prompts Used During Development

### Prompt 1 – React Application Structure

I asked AI to help plan the structure of a React expense tracker and identify appropriate components.

Example prompt:

> Build a React personal expense tracker application. Help me plan the component structure and explain how the components should work together. I want to understand the logic rather than simply copying the code.


### Prompt 2 – Expense Form

I used AI to help develop the expense form for entering expense information.

Example prompt:

> Help me implement an expense form in React that allows the user to enter an expense name, amount, category, and date. Explain the state management and form handling logic.

### Prompt 3 – Expense List and Delete Functionality

I asked AI for help implementing the display and deletion of expenses.

Example prompt:

> Help me create a React expense list that displays the expense name, category, date, and amount, with a delete button for each expense. Explain how the data should flow between the components.

### Prompt 4 – Filtering

I used AI to understand and improve expense filtering.

Example prompt:

> Help me implement an expense filter in React that allows users to filter expenses by category. Explain the filtering logic and how it should interact with the expense list.

### Prompt 5 – UI and CSS Improvements

After the main functionality was working, I used AI to review and improve the application's visual design.

Example prompt:

> Review the existing expense tracker UI and suggest improvements to the forms, cards, buttons, spacing, typography, colors, and responsive layout while keeping the application simple and user friendly.

### Prompt 6 – Debugging

AI was also used when I encountered development and runtime issues.

Example prompt:

> I am getting an error while running my React/Vite application. Analyze the error, explain what is causing it, and give me step-by-step instructions to troubleshoot it.

### Prompt 7 – Code Review and Refactoring

I asked AI to review the existing implementation rather than completely replacing it.

Example prompt:

> Review my existing React implementation and identify areas that can be improved, simplified, or refactored. Do not rewrite the entire application. Explain what should be changed and why.

## 4. How AI Assisted Throughout Development

AI was used as a development assistant rather than as a replacement for the development process.

During the project, AI helped me:

1. Plan the application's component structure.
2. Understand React state and component communication.
3. Implement and troubleshoot form functionality.
4. Implement expense filtering and deletion.
5. Improve the application's CSS and visual design.
6. Understand and resolve Vite development issues.
7. Review code for possible improvements.
8. Explain errors and suggest troubleshooting steps.
9. Review the application after implementation and identify areas for improvement.

I tested the application locally during development and checked the behavior of the features after making changes.

## 5. Manual Improvements and Corrections

After reviewing AI-generated suggestions, I manually tested and adjusted the application instead of accepting every suggestion automatically.

Examples of manual review and improvements include:

### UI Review

I manually reviewed the application's layout and adjusted the visual presentation of:
- Expense cards
- Forms
- Buttons
- Category controls
- Spacing
- Typography
- Responsive layout

### Functional Testing

I manually tested the application's core functionality, including:
- Adding expenses
- Selecting categories
- Entering dates
- Displaying expenses
- Deleting expenses
- Filtering expenses
- Calculating total spending
- Displaying spending by category

### Debugging and Corrections

When an AI suggestion did not work as expected, I tested the application and investigated the problem instead of assuming the generated solution was correct.

I also corrected issues encountered while running the Vite development server and testing the application locally.

### Code Review

I reviewed the generated code and kept the parts that were appropriate for the project while modifying or removing suggestions that did not fit the application's existing structure.

## 6. Development Approach

My development process followed this general workflow:

1. Understand the assignment requirements.
2. Plan the React application structure.
3. Build the main functionality.
4. Use AI to assist with implementation and explanations.
5. Run and test the application locally.
6. Identify errors or areas for improvement.
7. Ask AI for debugging or improvement suggestions.
8. Review the suggested changes.
9. Manually modify and test the implementation.
10. Deploy the completed application.
11. Review the final application through the live deployment.

The goal was to use AI as a development partner while still understanding, reviewing, testing, and making decisions about the resulting code.
